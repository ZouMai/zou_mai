🔎 Les détectives de l'échiquier

Objectif : chercher plusieurs suites de coups, prévoir la réponse adverse et expliquer pourquoi une solution fonctionne.

1 · Étude collective : la dame et les pions

Les blancs gagnent s'ils amènent un pion sur la 8e rangée. La dame noire gagne si elle capture tous les pions.

Quel premier coup est le meilleur ?

Ce coup échoue contre une défense correcte : 1. f6 Df5 2. d6 De6, ou 1. f6 Df5 2. e6 Dxf6. Cherche une autre possibilité.
Bonne piste ! 1. e6 Dxf5 2. e7 Df7 : les blancs gagnent. Autre réponse : 1. e6 De4 2. d6 Dxf5 : les blancs gagnent. Compare les deux réponses de la dame.

2 · Étude 1 : la tour et les pions

Les noirs commencent. Les blancs doivent gagner malgré la tour. Examine séparément les deux premiers coups de la tour.

Suite officielle : 1… Ta5 2. f6 Txe5 3. f7. Les blancs gagnent.
Suite officielle : 1… Te1 2. e6 Te5 3. f6 Txe6 4. f7. Les blancs gagnent.

3 · Étude 2 : le cavalier contre les pions

Les blancs jouent, mais les noirs doivent gagner. Compare les deux plans et retrouve les sauts du cavalier.

1. f5 Cf3 2. f6 Cg5 3. f7 Cxf7 4. g5 Cxg5. Les noirs gagnent.
1. g5 Cf5 2. g6 Cg7 3. f5 Cxf5 4. g6 Cxg6. Les noirs gagnent.

4 · Étude 3 : le fou contre les pions

Les blancs cherchent à promouvoir un pion. Les noirs peuvent aussi gagner en amenant leur pion sur la première rangée.

Quel plan blanc fonctionne ?

1. f5 Ff6 2. g5 Fxg5 3. f6 Fxf6. Les noirs gagnent : ce plan échoue.
1. g5 a5 2. f5 a4 3. f6 Fxf6 4. gxf6 a3 5. f7 a2 6. f8 : les blancs gagnent par promotion !

5 · Bataille à 15 points

Compose ton armée en respectant le budget. Dame : 10, tour : 5, fou : 3, cavalier : 3, pion : 1.

Total : 15/15

Les pions commencent sur la 2e rangée ; les pièces sur leur case de départ. Une tour ou une dame doit avoir un pion devant elle. La partie se joue ensuite sur un échiquier.

  3. J'ai vérifié plusieurs coups avant de décider.
