G4 · Enrichir le groupe nominal

Transforme des phrases simples en phrases plus précises grâce aux expansions du nom.

📖 Je retiens

Dans une phrase, un groupe nominal (GN) est organisé autour d'un nom noyau. On peut l'enrichir pour apporter des précisions.

Phrase de départ :

Le garçon observe un oiseau dans le jardin.

1. Avec un adjectif qualificatif : il apporte une précision sur le nom et s'accorde avec lui.

Le jeune garçon observe un oiseau dans le jardin.

2. Avec un complément du nom (CDN) : il complète le nom, souvent à l'aide d'une préposition (de, à, en, pour, sans…).

Le garçon du village observe un oiseau dans le jardin.

3. Avec les deux expansions : le même GN peut contenir un adjectif et un complément du nom.

Le jeune garçon du village observe un oiseau dans le jardin.

Observe le GN sujet entier : « Le jeune garçon du village ». Son déterminant est « Le », son nom noyau est « garçon », son adjectif est « jeune » et son complément du nom est « du village ».

Repère : vert = adjectif ; bleu = complément du nom ; nom noyau souligné.
